D&L ACC - نسخة الإدارة المتصلة بـ Supabase

- admin.html هو صفحة الإدارة الجديدة بالـ Sidebar.
- admin.js متصل بنفس مشروع Supabase الموجود في المشروع.
- لا توجد بيانات كوبونات/طلبات تجريبية داخل HTML؛ الأرقام والقوائم تُقرأ من قاعدة البيانات.
- تم الاحتفاظ بنسخة الصفحة القديمة باسم admin_legacy_backup.html.
- تم إضافة fallback للكوبونات في script.js: يحاول RPC الموجود أولاً، ثم يستخدم جدول coupons إذا لم يتوفر الـ RPC.
- لا تحتاج لكتابة SQL جديد لكي تفتح الصفحة. إذا كان جدول orders أو coupons غير موجود أصلًا في مشروع Supabase، ستظهر رسالة واضحة لهذه الميزة بينما يظل الموقع يعمل.
- بيانات المنتجات والصور والإعدادات والتقييمات تستخدم Supabase حسب الكود الحالي.
